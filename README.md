# Ayman Elsawy Khalifa — Portfolio

A personal portfolio site built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deployment

Deployed on **Cloudflare Pages**, connected to this GitHub repo for auto-deploys on every push to `main`.

- Build command: `npm run build`
- Build output directory: `dist`

To connect for the first time: go to the [Cloudflare Pages dashboard](https://dash.cloudflare.com/?to=/:account/pages), create a project from this Git repository, and use the build settings above.
